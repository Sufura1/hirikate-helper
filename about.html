О проекте

HIRIKATE Helper

Open-source проект для автоматизации RP-отыгровок в AMAZING ONLINE. Делаем отыгровку быстрой, точной и профессиональной.

Что такое HIRIKATE Helper

Это внешний WPF-оверлей поверх AMAZING ONLINE: фиксация ID цели, чтение HP/AP, 89 готовых макросов по горячим клавишам, справочники прямо в игре и полная настройка под себя. Безопасен, ничего не инжектит в игру.

Проект развивается поэтапно: queue команд против флуда, гварды выполнения, автобэкапы, диагностика, темы и инлайн-интерфейсы. Свой набор консольных тестов, сборка без предупреждений.

C#.NET 8.0 (WPF)AutoHotkey 1.1WinAPIInno SetupJSON / INI

Стек проекта

  • C# / .NET 8.0 (WPF) — оверлей, память, хоткеи;
  • AutoHotkey 1.1 — радиальные меню, hotstrings-справочники;
  • WinAPI — RegisterHotKey, ReadProcessMemory, SendInput;
  • Inno Setup — установщик и раздача;
  • JSON / INI — конфиги, профили, темы.

Принципы

  • Безопасность — ничего не входит в процесс игры;
  • Скорость — отыгровка одним нажатием, анти-флуд;
  • Надёжность — бэкапы, миграции, 50 тестов;
  • Удобство — 22 темы, инлайн-настройка, профили.
