# Быстрый старт

Что это?

HIRIKATE Helper — внешнее WPF-приложение (.NET 8.0) + AHK-скрипты для автоматизации RP-отыгровок в AMAZING ONLINE. Оверлей не забирает фокус и работает поверх игры.

Принцип работы

  1. Программа работает снаружи игры (не инжектит DLL);
  2. Читает память через ReadProcessMemory — легально и пассивно;
  3. Отправляет команды двумя способами:
    • WriteProcessMemory — прямая запись в чат игры;
    • SendInput — эмуляция клавиатуры через AHK.
  4. AHK-скрипты нажимают клавиши радиального меню и hotstrings-справочники.
Безопасно: нет DLL в процессе игры, только чтение памяти + эмуляция ввода. Античит не детектирует.

# Установка

Пошагово

  1. Скачать HIRIKATE-Helper_Setup.exe с страницы загрузки;
  2. Запустить установщик (требуются права администратора);
  3. Выбрать папку установки (по умолчанию C:\Program Files\HIRIKATE Helper);
  4. Отметить галочки: AutoHotkey 1.1 и ярлык на рабочем столе;
  5. Готово — запустите программу и выберите организацию.

Требования

  • Windows 10/11 x64;
  • .NET 8.0 Runtime (проверяется при установке);

  • AMAZING ONLINE: amazing.exe (GTA:SA:MP + AZMP).

Core/MemoryReader.cs
// MemoryReader.cs — чтение HP игрока через ReadProcessMemory
public float PlayerHealth
{
    get
    {
        int pedPtr = ReadInt((IntPtr)0xB6F5F0);
        if (pedPtr == 0) return 0;
        return ReadFloat((IntPtr)(pedPtr + 0x540));
    }
}

# Справочники

Встроенные отыгровки-подсказки, вызываемые hotstring-ами в игре.

1. СВУ (ВЧ)

  • Типы ВУ: СВУ, пояс смертника, растяжки, мины;
  • Виды: механические, дистанционные (С4);
  • Оборудование: БРВУ, ДРП, КТЗ, ЭТЦ-3, Фонтан-2;
  • Иерархия проводов: Фазный → Заземление → Телемеханика → Дискретный → Минусовой;
  • Правила обезвреживания (8 шагов).

2. Первая помощь (ЕСС)

  • Кровотечения: капиллярное, венозное, артериальное;
  • СЛР: 30:2, дефибриллятор, адреналин;
  • Переломы: закрытый/открытый, шина, остеосинтез;
  • Ожоги: 1-4 степень, ПХО, пересадка кожи;
  • Состояния: обморок, инсульт, инфаркт, отравление.

3. Штурм (ФСБ/ОСН)

  • Группы: штурмовая, закрепления, резерв, мобильная;
  • Тактики: Крючок, Крест, Угол-1/2, Диагональ, Четвёрка, Смежный;
  • Команды: Контакт, Движение, Работаю, Красный/Зелёный;
  • Ориентация по часам: 3 часа (справа), 9 часов (слева).

4. Переговоры

  • Цели: узнать количество, затянуть время, собрать инфу;
  • Последовательность: подготовка → прибытие → работа с заложником;
  • Вопросы: требования, время, зелёный коридор, передача заложника, ВУ.

# Отыгровки: создание и редактирование

Полный гайд из программы: как создать макрос с нуля, отредактировать готовый, какой формат шагов и какие переменные-шаблоны можно подставлять.

Отыгровка — набор шагов, выполняемых по нажатию горячей клавиши: текст/команда в чат и/или нажатия клавиш с задержками. Каждая строка в поле «Шаги» — один шаг.

Как создать

  1. Нажми «Добавить новую» — появится пустой макрос;
  2. Задай «Комбинацию» — впиши вручную или нажми «Показать клавиши» и нажми нужное сочетание (Esc — отмена);
  3. Впиши шаги в поле «Шаги» (формат ниже);
  4. Нажми «Сохранить макрос» — отыгровка готова и появится в списке организации.

Как отредактировать

  1. Выбери макрос в списке организации → «Загрузить»;
  2. Поправь «Комбинацию», поле «Шаги» или галочку «Скрыть отыгровку»;
  3. «Сохранить макрос» — изменения применятся.

«Тест» — выполнить весь макрос сразу; «По шагам» — по одному с подтверждением. «Удалить» — убрать макрос полностью, «Скрыть отыгровку» — отключить без удаления.

Формат шагов

Одна строка = один шаг. Любая ошибка в шагах подсветится подсказкой, а кнопки «Сохранить» и «Тест» заблокируются.

ФорматЗначение
задержка|текст Сообщение/команда в чат; задержка в мс после шага
press задержка|клавиша|кол-во Нажатие клавиши (Enter, Numpad1, F6, sc-сканкод); «кол-во» — по умолчанию 1
Пример отыгровки — МВД · Alt+5 · «Личный досмотр»
500|/me достал перчатки из кармана, надел перчатки на руки
500|/do Перчатки на руках
750|/me начал прохлопывать верхние и нижние слои одежды человека напротив
250|/frac {m}
press 250|1|2
press 250|5|2
press 250|1|2
press 300|Enter|1

Проверка макроса

Перед сохранением и запуском текст шагов проверяется автоматически. Ошибки блокируют «Сохранить» и «Тест», предупреждения — не мешают, но показывают риск:

ТипПримеры
Ошибка нет разделителя |; задержка не число; пустой текст или пустая скобка {}; неизвестная переменная; клавиша enter строчными (нужен Enter); неизвестная клавиша нажатия
Предупреждение нулевая или слишком большая задержка; сообщение длиннее 300 символов; повтор предыдущей фразы (сработает защита от флуда); больше 10 нажатий подряд; открытая скобка { без закрывающей

Полезно знать

  • «Ввести ID» (Numpad0) — служебный макрос, он не редактируется;
  • «Скрыть отыгровку» — отключить без удаления, «Удалить» — убрать совсем;
  • Комбинация, занятая другим макросом или зарезервированная скриптом организации, не сработает — программа предупредит;
  • Макросы привязаны к выбранной организации: переключи организацию — и список отыгровок станет из её набора;
  • Макрос выполняется только когда окно игры активно — иначе появится «Игра не активна»;
  • Аварийная остановка текущего макроса — Ctrl+Alt+Pause или Ctrl+Alt+Backspace.

# Безопасность

Что делает программа:
  • ✅ Чтение памяти (ReadProcessMemory) — пассивное, легальное
  • ✅ Эмуляция клавиатуры (SendInput через AHK) — легитимный ввод
  • ✅ Запись в чат (WriteProcessMemory по offset 0x26E8C8) — аналог AZMP-клиента
Что программа НЕ делает:
  • ❌ DLL-инъекция в amazing.exe
  • ❌ Модификация кода игры
  • ❌ Перехват DirectX/OpenGL
  • ❌ Чтение защищённых областей

Модули в процессе игры

При EnumProcessModules в игре видны только gta_sa.exe, azmp.dll и системные библиотеки. HIRIKATE-Helper.dll и AutoHotkey.dll в процесс игры не попадают — это отдельные процессы.
