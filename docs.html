# Быстрый старт

Что это?

HIRIKATE Helper + Studio v1.2.0 — профессиональный RP-ассистент для AMAZING ONLINE.
Важно: большой интерфейс с вкладками полностью удалён. В игре отображается только компактный GTA HUD 470×252 (не забирает фокус, WS_EX_NOACTIVATE). Всё редактирование (профиль, макросы, темы, параметры) вынесено в отдельное приложение HIRIKATE Studio.

Принцип работы

  1. Программа работает снаружи игры (не инжектит DLL);
  2. Читает память через ReadProcessMemory — легально и пассивно;
  3. Отправляет команды через AHK-мост (обмен через temp-файлы с синхронизацией PING/PONG);
  4. AHK-скрипты нажимают клавиши радиального меню и hotstrings-справочники.
Безопасно: нет DLL в процессе игры, только чтение памяти + эмуляция ввода. Античит не детектирует.

# Установка

Пошагово

  1. Скачать HIRIKATE_Setup.exe (1.84 МБ) с страницы загрузки;
  2. Запустить установщик от имени администратора;
  3. Выбрать папку установки (по умолчанию C:\Program Files\HIRIKATE);
  4. Установщик автоматически разместит HIRIKATE Helper (HUD) и HIRIKATE Studio (редактор) в одной папке с общими Data/ и Core/;
  5. Готово — запустите Studio для настройки профиля, затем Helper для игры.

# Справочники

Встроенные отыгровки-подсказки, вызываемые hotstring-ами прямо в игре (файл guides.ahk).

1. СВУ (ВЧ)

  • Типы ВУ: СВУ, пояс смертника, растяжки, мины;
  • Оборудование: БРВУ, ДРП, КТЗ, ЭТЦ-3, Фонтан-2;
  • Иерархия проводов: Фазный → Заземление → Телемеханика → Дискретный → Минусовой;
  • Правила обезвреживания (8 шагов).

2. Первая помощь (ЕСС)

  • Кровотечения: капиллярное, венозное, артериальное;
  • СЛР: 30:2, дефибриллятор, адреналин;
  • Переломы: закрытый/открытый, шина, остеосинтез;
  • Ожоги: 1-4 степень, ПХО, пересадка кожи.

3. Штурм (ФСБ/ОСН) и Переговоры

  • Тактики: Крючок, Крест, Угол-1/2, Диагональ, Четвёрка;
  • Переговоры: выяснение требований, затягивание времени, зелёный коридор.

# Отыгровки: создание и редактирование

Важно: Редактирование макросов происходит только в HIRIKATE Studio (вкладка «Отыгровки»). Helper только выполняет их в игре.

Как создать в Studio

  1. Откройте HIRIKATE Studio → вкладка «Отыгровки»;
  2. Нажмите «Добавить новую»;
  3. Задайте «Комбинацию» (ввод вручную или запись по нажатию клавиш);
  4. Впишите шаги в поле «Шаги» и нажмите «Сохранить макрос».

Формат шагов

ФорматЗначение
задержка|текстСообщение в чат; задержка в мс после шага
press задержка|клавиша|кол-воНажатие клавиши (Enter, Numpad1, F6, sc-сканкод)

Переменные-шаблоны

В шагах можно подставлять данные из player.ini и цели. Если переменная не найдена — валидация в Studio выдаст ошибку и заблокирует кнопку «Сохранить».

ПеременнаяЗначение
{nick}, {fio}, {rank}, {org}Данные персонажа из player.ini
{m} / {target_id}ID зафиксированной цели (Numpad0)
{target_nick}Ник цели (если определен)
{chase} / {deject}Авто-выбор команды погони (/chase или /chaseid) / высадки

# Конфигурация

Все настройки хранятся в папке Data/ и являются общими для Helper и Studio.

Основные файлы

  • config.json — Bindings (отыгровки), CurrentOrg, FixedTargetId, ConfigVersion=4.
  • settings.ini — Тема (CurrentTheme), прозрачность, анимация перелива, фраза «Представиться».
  • player.ini — Ник, ФИО, ранг, должность, организация, контакты (Discord, VK, Telegram).
  • id_history.json — История последних 10 зафиксированных ID (для быстрого вызова через Alt+1..9).
  • backups/ — Автоматические zip-архивы конфигов перед обновлениями или критическими изменениями.

# Безопасность

Что делает программа:
  • ✅ Чтение памяти (ReadProcessMemory) — пассивное, легальное
  • ✅ Эмуляция клавиатуры (SendInput через AHK) — легитимный ввод
  • ✅ Обмен данными через временные файлы (Temp)
Что программа НЕ делает:
  • ❌ DLL-инъекция в amazing.exe
  • ❌ Модификация кода или памяти игры (только чтение)
  • ❌ Перехват DirectX/OpenGL

При проверке процессов (EnumProcessModules) в игре видны только gta_sa.exe, azmp.dll и системные библиотеки. Процессы HIRIKATE работают изолированно.
