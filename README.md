Официальный сайт-документация десктопного RP-ассистента **HIRIKATE Helper** для игроков
AMAZING ONLINE (GTA:SA:MP). Сайт собран по ТЗ из `C:\Users\misaf\Desktop\Текстовый документ (10).txt`
с учётом фактической структуры проекта `F:\PROGECT2`.

## Структура сайта

```
F:\SAIT\
├── index.html          — главная (hero, возможности, организации, как работает, загрузка)
├── docs.html           — документация (сайдбар, поиск, модули, AHK, конфиги, безопасность)
├── download.html       — скачивание (версии, changelog, требования, инструкция)
├── organizations.html  — 5 организаций (МВД [ППС/УМВД, ДПС/ГАИ], ФСБ, ВЧ, ЕСС, ФСИН)
├── faq.html            — частые вопросы (аккордеон)
├── about.html          — о проекте, автор, контакты, лицензия
├── styles.css          — дизайн-система (тёмная тема, glassmorphism, киберпанк)
├── app.js              — интерактив (preloader, тема, поиск, копирование, аккордеоны, модалки)
├── logo.svg            — логотип (щит с H)
└── README.md
```

## Технологии

- HTML5 (семантическая разметка), CSS3 + Tailwind CSS (CDN)
- JavaScript (ES6+), Font Awesome 6, Prism.js (подсветка C#/AHK/JSON/INI)
- AOS (анимации по скроллу), Google Fonts (Inter + JetBrains Mono)
- Адаптивность 320px → 1920px+, тёмная/светлая тема, PWA-готовность

## Запуск локально

Сайт статический — откройте `index.html` двойным кликом, либо запустите локальный сервер:

```bash
# Python
python -m http.server 8080
# → http://localhost:8080

# Node.js (npx)
npx serve .
```

## Что заменить под прод

1. **Ссылки «Скачать»** — в `index.html`, `download.html` у кнопок класс `dl-btn` и `data-file="HIRIKATE-Helper_Setup.exe"`.
   Реальный файл лежит в `F:\PROGECT2\MvdHelper\Installer\Output\HIRIKATE-Helper_Setup.exe`.
   Положите его **в корень сайта** (без папок) — `HIRIKATE-Helper_Setup.exe` рядом с `index.html`.
2. **Скриншоты** — добавьте реальные скриншоты программы **в корень сайта** (папок нет).
   (`F:\PROGECT2\Screenshots` пуста — приложение запускается поверх игры.)
3. **OG-изображение** — замените `logo.svg` на полноценное `og-image.png` 1200×630.
4. **Контакты/соцсети** — проверьте ссылки на Discord/VK/Telegram в подвале и на `about.html`.
5. **GitHub** — добавьте ссылку на репозиторий, если он появится.
6. **Видео-гайд** — вставьте YouTube/Vimeo плеер вместо заглушки на `download.html`.
