Системные требования

Проверьте своё железо

💻

ОС

Windows 10 / 11 x64. Программа — портабельная и лёгкая, работает фоном поверх игры.

⚙️

.NET 8.0 Runtime

Проверяется при установке. При отсутствии установщик предложит скачать рантайм.

⌨️

AutoHotkey 1.1

Версия 1.1.37.01, опционально (ставится в комплекте). Нужен для радиальных меню.

💾

100 MB свободно

Вместе с рантаймом. Сам установщик занимает всего ~1.5 MB.

🛡️

Права администратора

Нужны при установке и для чтения памяти игрового процесса.

🎮

AMAZING ONLINE

Игра запущена: amazing.exe (GTA:SA:MP + AZMP.dll) для работы оверлея.
